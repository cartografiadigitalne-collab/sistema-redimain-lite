# SOGNE Lite - Sistema de Geointeligencia (Versión Lite)

Este proyecto es una versión ligera (**Lite**) del sistema principal `sistema-redimain`. 

### Capas Incluidas:
1. **Capas Base**:
   - Municipios
   - Parroquias
   - Sectores
2. **Salud e Infraestructura**:
   - Hospitales
   - Clínicas
   - Ambulatorios
   - CDI (Centro de Diagnóstico Integral)
   - Escuelas

### Excluidos en esta versión:
- Cuadrantes de Paz (Puntos / Polígonos)
- COMPAS
- Zonas de Riesgo / Incidencias
- Geocalizaciones / Tráfico / Actores
- Bandas Delictivas / GEDO
- Servicios Básicos (Agua, Electricidad, Gas)
- Antenas de Telecomunicaciones
- Rutas y Terminales de Transporte

### Ejecución Local:
```bash
npm run dev
```
